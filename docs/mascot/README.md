# voice-claude 的形象

两位：**Cadence（声纹蓝铃）**——戴耳机的橙发洛丽塔少女，和她的伙伴**胖鱼**——戴耳机的蓝色圆鱼。

- `../../voiceclaude/assets/mascot_chibi.png`：Q 版标准图（2.8 头身），图标、头像、表情包都从它出。
- `../../voiceclaude/assets/avatar.png` / `voice-claude.ico`：从标准图裁出的圆头像和窗口图标。
- `../../voiceclaude/assets/mascot_tall.png`：等身版标准图（约 4 头身），启动页、README、白板空白页用。
- `../../voiceclaude/assets/fish.png`：胖鱼的标准图。
- `design.md`：服装设计书（参考研究、逐部位设计、借鉴对照、定稿备注、生图提示词）。
- `../../scripts/mascot/`：生成流程，再出新图（表情、姿势、等身版）用它。

形象是本项目的原创设计，随仓库按 MIT 许可分发。画风取自 2026 年中文互联网"AI 娘化"二创的路子（见设计书第 3 节），
没有复制任何画师的作品、任何品牌的印花或标志。
